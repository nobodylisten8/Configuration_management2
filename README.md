# Dependency Graph Visualizer

Инструмент визуализации графа зависимостей для менеджера пакетов.

## Этап 1: Минимальный прототип с конфигурацией

Реализовано минимальное CLI-приложение, которое принимает параметры через опции командной строки, валидирует их и выводит конфигурацию в формате ключ-значение.

### Настраиваемые параметры

| Параметр | Описание | Обязательный | По умолчанию |
|----------|----------|--------------|--------------|
| `--package` | Имя анализируемого пакета | Да | — |
| `--repo-url` | URL репозитория или путь к файлу | Да | — |
| `--test-mode` | Режим работы с тестовым репозиторием | Нет | `False` |
| `--version` | Версия пакета | Нет | `latest` |
| `--output-file` | Имя файла с изображением графа | Нет | `graph.png` |
| `--ascii-tree` | Вывод зависимостей в формате ASCII-дерева | Нет | `False` |

### Установка и запуск тестов

```bash
pip install pytest
python -m pytest tests/
```
